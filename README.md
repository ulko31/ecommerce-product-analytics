# E-commerce Product Analytics

Аналитический проект на данных бразильского marketplace Olist.
**Направление:** Product Analytics / Data Analytics

## Цель проекта

Проанализировать продажи и поведение клиентов e-commerce платформы, рассчитать ключевые продуктовые и бизнес-метрики и найти потенциальные зоны роста.

## Что было проанализировано

- выручка и средний чек;
- динамика заказов и продаж;
- повторные покупки;
- когортный retention;
- товарные категории;
- сроки доставки;
- пользовательские оценки;
- связь задержек доставки с review score.

## Стек

SQL, SQLite, Python, pandas, matplotlib

## Основные результаты

- Выручка по доставленным заказам составила около **15,4 млн**.
- Средний чек — **159,86**.
- Только около **3% клиентов** совершили более одного доставленного заказа.
- Когортный анализ показал низкий уровень повторных покупок после первого заказа.
- Средний фактический срок доставки составил **12,6 дня**.
- **6,77%** доставок были выполнены позже обещанного срока.
- Средняя оценка снижается с **4,29** для заказов, доставленных вовремя, до **1,73** при задержке более 8 дней.

## Основные выводы

Одной из потенциальных зон роста является повышение доли повторных покупок и удержание клиентов.

Также анализ показал заметную связь между задержками доставки и снижением пользовательской оценки, поэтому качество и стабильность доставки могут быть важным направлением для улучшения customer experience.

## Возможные следующие шаги
